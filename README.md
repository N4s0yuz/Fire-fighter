# Fire-fighter Robot
## Introduction
Robot cứu hỏa sử dụng STM32 và ESP32-CAM để:
- Dò đường
- Tránh vật cản
- Phát hiện lửa
- Giám sát không dây qua camera
## Hardware
- STM32F103C8T6
- ESP32-CAM
- HC-SR04
- Flame sensor
- L298N
- Motor 12V
- Pump
- Servo MG90S
## Features
- Điều khiển động cơ
- Streaming camera qua WiFi
- Phát hiện lửa
- Tránh vật cản
- Điều khiển thủ công/tự động
## Folder Structure
Control-STM32/     # STM32 firmware
Control-esp32/     # ESP32-CAM source
## Installation
1. Clone repo
2. Open STM32 project
3. Flash firmware
4. Upload ESP32-CAM code
